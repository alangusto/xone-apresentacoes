# X-ONE IT · Propostas de apresentação

Site estático publicado pelo GitHub Pages. Todo o conteúdo está criptografado (AES-256-GCM);
a chave de cada usuário é derivada da senha (PBKDF2-SHA256, 600000 iterações).
Sem usuário e senha válidos, os arquivos deste repositório não podem ser lidos.

Para trocar senhas ou incluir usuários, os arquivos são gerados de novo a partir dos originais.
